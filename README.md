# 铁皮黎明 · Iron Dawn

> Aholo Lux3D 全球 3D AI 黑客松参赛作品 —— 三域（陆 / 海 / 空）载具对战的 3D 战术射击游戏。
> Unity 6000.3.27f1 · Built-in 渲染管线 · 全部载具与场景物件由 **Aholo Lux3D** 生成

---

## 这是什么

一个「坦克 + 炮艇 + 飞机」同场作战的小型对战游戏：六台载具、一张 2 km × 2 km 的战场、
资源点占领、金币经济、换车与复活。核心是**三种域的手感差异**——坦克爬坡会打滑、
炮艇会搁浅、飞机有进气口涡轮和独立的飞行操控。

美术资产不是买来的：**所有载具模型（6 台 + 炮塔/炮管/履带分件）都由 Lux3D 文生 3D 生成**，
再经 Blender 摆正、拆件、补面。原始 GLB 全部在 `ArtSource/Lux3D/` 下，可追溯。

## 怎么跑

1. 用 **Unity 6000.3.27f1** 打开本目录（`ProjectSettings` 已锁定版本）。
2. 打开场景 `Assets/Scenes/Map_Battlefield.unity`。
3. 按 Play。首帧会由 `MatchManager` 自动生成战场与双方载具。

> 工程不含 `Library/`、`Builds/`（已在 `.gitignore` 里），首次打开需要 Unity 重新导入，约 1–2 分钟。

## 操作

| 键 | 作用 |
|---|---|
| W / A / S / D | 驾驶（飞机为俯仰 + 滚转） |
| 鼠标 | 瞄准（坦克/炮艇：炮塔跟视角；飞机：机头指向） |
| 左键 / 空格 | 开火 |
| **Shift** | **开镜**（坦克：炮镜；飞机：粘在机头的瞄准具） |
| 右键 | 轻微放大 |
| 滚轮 | 拉远拉近 |
| 按住 C | 自由环视 |
| Q | 切换武器 |
| 1 / 2 / 3 | 切换弹药 |
| G | 回车库换车 |

## 已实现

- **三域载具物理**：贴地/随地形倾斜/打滑/涉水/深水沉没；浮力/吃水/搁浅；固定高度飞行 + 侧倾
- **载具外观**：Lux3D 生成的 6 台载具 + Blender 重做的炮塔、程序化履带（环带 + 主动轮 + 负重轮）、进气口涡轮风扇
- **战斗**：炮塔限速转动、弹道、三层伤害（正面/侧面/背面）、命中判定、开火镜头抖动
- **瞄准**：坦克/炮艇的准星画在炮口方向（跟着炮塔滞后，炮口出画面时贴边显示箭头）；开镜后镜头粘在炮管里
- **音效**：按域区分的发动机循环音（柴油机 / 喷气 / 螺旋桨），随车速变调
- **对局**：资源点占领、金币经济、复活递增、换车涨价、结算面板
