### 1.2 "下面没生成明白"的真因与修法（**最重要**）

用户反馈的是**楼底和地面之间有缝/空**。这里有两个独立原因，都修了：

1. **模型底部不闭合**：Lux3D 出的楼底面经常是开的，或者底下甩几片碎渣。
   旧的 `Place()` 用"模型最低点"贴地 → 被那几片碎渣顶着，整栋楼悬空。
2. **地基缺失**：就算贴地，坡地上楼底一侧必然露缝。

**修法：每栋楼垫一块地基裙边**（`PropScatter.AddFoundation`）：

- 尺寸 = **该栋楼渲染体世界包围盒的 1.06 倍**（不是"水平半径×2"！
  半径取的是长深里较大的那个，窄长楼（断墙 14×3）会算出一块 14×14 的大灰板铺在草地上 ——
  这是第一版的翻车点，截图一眼就看出来了）。
- 中心在地面下 **1.28 m**、总高 3.0 m → 上沿只露 **0.22 m**，往下埋 2.78 m，坡地上也不露空。
- 材质 `Assets/Materials/Props/foundation_concrete.mat`，颜色 `(0.33,0.315,0.29)` 压暗，别在草地上跳。
- 带 BoxCollider（实心），车撞得住。

### 1.3 白模事故（改建筑必看）

第一版重新撒完，**所有楼都是纯白**。原因链：

1. Lux3D 的 FBX 里材质叫 `Designer_Logic_PBR`，**没有贴图**（`_MainTex = NULL`）。
   Blender 虽然 `embed_textures=True`，但 Unity 不会把它变成可用的 Texture 子资产。
2. 颜色/贴图本来靠 `PropScatter.ApplyPalette()` → `LuxMaterialFor(modelName)` 换成 `Assets/Materials/Props/LUX_<模型名>.mat`。
3. `LuxMaterialFor` 里写的是 `if (!name.StartsWith("tree_") && !name.StartsWith("building_")) return null;`
   —— **新名字 `waste_*` 一个都不匹配**，于是返回 null、保留原材质（无贴图+纯白）。
4. 而且贴图要先从 glb 抽出来放到 `Textures/<模型名>/BaseColor.png`。

**结论**：以后再加新的 Lux3D 模型族，必须同时改三处 ——
`LuxMaterialFor` 的前缀白名单、抽 `BaseColor.png`、`BuildingScale` 的高度映射。

### 1.4 高度映射

`BuildingScale` 原来只认 `skyscraper` / `low-detail`，新名字全落到 "20~40 m" 兜底，
连 4 米的铁皮棚都会被拉成高楼。已按新名字重写：

| 名字含 | 目标高度 |
|---|---|
| `tower` | 30~38 m |
| `block_mid` | 16~21 m |
| `block_low` | 9~13 m |
| `warehouse` | 8~11 m |
| `shack` | 4~6 m |
| `wall` | 3~4.5 m |

## 2. 打不穿 + 烟尘（第 3 条）

- **打不穿**：建筑碰撞第一轮已经从"整栋一个实心盒"改成**每网格一个 MeshCollider**
  （`convex = false`），炮弹射线一撞到网格就 `Destroy`，穿不过去。
  实测：从玩家眼睛朝墙打 `RaycastAll`，第一个命中就是 `waste_wall @39.0 m`，
  第二个 51.4 m 是同一堵墙的背面 —— 中间没有穿插。
- **烟尘**：`ExplosionFx.Impact(pos, normal, scale)`（新加的），沿命中面法线喷一团**灰白烟尘**
  （无火球、无强光），0.55~1.35 s 生命、30 粒、重力 0.22、尺寸随寿命涨到 1.9 倍。
  - 炮弹命中非载具物体 → `scale = 3.4`；机枪弹 → `1.3`。
  - 颜色特意调得比墙亮一档（0.88 灰白），否则打在灰墙上完全看不见 ——
    第一版用 0.74 就"打到墙上像什么都没发生"。
- 顺带把炮弹的销毁点改成"命中就炸"，不再无声消失。

## 4. 受击方向指示（第 5 条）

用户原话："显示别人距离的那个箭头不要了，被打的时候才显示一下，不过也不能用这种水平的箭头了，
因为现在的箭头我都看不出来敌人在哪，很废物。"

- **删**：常显的屏幕外威胁箭头（`DrawThreatArrow` 的调用点全部去掉，函数保留未用）。
- **加**：`MatchHUD.ShowDamageFrom(worldPos)` + `DrawDamageDirection()` ——
  在屏幕中心外 0.30×屏高 的一圈上，画一段 **40° 的红色圆弧**，弧心正对打你的人的方位，
  1.6 s 内平方衰减淡出，弧两端各加一个小三角。
- 触发点：`VehicleCombat.TakeHit()` 里 `if (IsPlayer && attacker != this) MatchHUD.ShowDamageFrom(hitFrom);`
  所以**只有真的挨打才出现**，且是"打我那个人的方向"，不是"附近有敌人"。
- 实测四个方向同时打，四段弧分别落在上/右/下/左（`work/ui_shots/B2_dmg_4dir.png`）。
