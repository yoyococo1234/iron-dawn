### 2.1 炮盾（gun shield）

原塔体正面是一块平墙，用户要求"加个炮盾"。做法（`work/build_gun_shield.py`）：

- 折弯板：正面一段 + 两侧各两段折边（俯视是包住前脸的护板，不是贴片）
- 尺寸：宽 1.94 m、高 1.21 m、**板厚 0.20 m**；前表面 Unity z = 1.50（塔体正面 1.448，凸出 0.05）
- 后表面 −1.30，**埋进塔体正面 0.148 m**（评审要求 ≥0.15 压住根部暗缝）
- 炮口座：短圆柱 r 0.38 × 长 0.20，炮管从里面穿出；+20° 仰角时炮管在座口截面的偏移仍在座内

历史版本留在 `Assets/Models/Vehicles/Split/sea_gunboat_turret_v3.fbx`（A 版：平顶+圆环）、

### 2.2 摇摆炮塔：从 1:1 一路退到 25%

**目标**：炮管上下动的时候，整块塔体也跟着动（像 AMX-13 的 FL-10 摇摆炮塔）。

**当前实现（可用版）**

| 项 | 值 |
|---|---|
| 切分面 | 塔体本地 z = 0.10（下=鼓形座圈，上=箱体+炮盾） |
| 塔体抬高 | **0.10 m** |
| 耳轴 `modelElevatingPivot` | (0, 0.95, 0.15)（炮塔本地坐标） |
| 跟随比例 `elevatingFollow` | **0.25**（炮管 12° → 塔体 3°） |
| 俯仰范围 | +12° / −6° |

| 静止环缝 | 0.10 m |
| 穿模 | ±3°/±2°/0° 全部 **0 对**相交三角面片 |

**试过、被否掉的 6 种结构（实测数据，别再走回头路）**

| 方案 | 抬高 | 穿模（BVH 相交面片对） | 为什么否掉 |
|---|---|---|---|
| 颈圈裙板（lower 加一圈墙） | 0 | 0°: **2069**，+12°: **6566** | 裙板 r1.12 比塔体对角半径 1.5 m 小，角插在裙里 |

| 塔体下侧斜切 + 座圈挖槽 | 0.06 | +9°: 371，+12°: 847 | 座圈内部是碎壳，槽壁做不干净 |
| 窄座圈(0.90×1.09) + 矩形外裙 | 0.30 | 0 | 视觉像一块大托盘 |
| **25% 微动（当前）** | **0.10** | **0** | 塔体只动 3°，是"表演"不是真机构 |

### `Assets/Scripts/Units/VehicleModelBinder.cs`（拆件炮塔分支）

开启 `oscillatingTurret` 后建两层：

```
Turret (yaw)
├── TurretRing     ← def.modelTurretLowerPrefab（不俯仰）
└── Elevating      ← 位于 modelElevatingPivot，按比例俯仰
    ├── TurretModel ← def.modelTurretPrefab（网格原点偏移要再减 elevatingPivot）
    ├── Barrel      ← 炮管（绕剩余角度俯仰）

    └── DeckGun     ← 甲板机枪跟着塔体动
```

同时设置 `vp.barrelBone = Barrel`、`vp.elevatingBone = Elevating`、
`vp.elevatingFollow = def.elevatingFollow`，并把 `maxElevation/maxDepression` 覆盖成 asset 里的值。

### `Assets/Scripts/Units/VehiclePhysics.cs`

```csharp
[System.NonSerialized] public Transform elevatingBone;
public float elevatingFollow = 1f;

void ApplyPitch()   // SetBarrelPitch / AimBarrelAt 都改成调它
{
    float follow = elevatingBone != null ? Mathf.Clamp01(elevatingFollow) : 0f;
    if (elevatingBone != null) elevatingBone.localRotation = Quaternion.Euler(-barrelPitch * follow, 0, 0);
    if (barrelBone   != null) barrelBone.localRotation   = Quaternion.Euler(-barrelPitch * (1 - follow), 0, 0);
}
```

**关键点**：俯仰角拆给两个节点，两者相加仍等于目标角度 → 瞄准、AI、准星、出膛点**一行都不用改**。

## 4. 几何结论（这是这一轮最值钱的东西）

塔体是**平底大方块**（1.9 × 2.9 m），耳轴在塔体中高处（0.95）。倾斜 θ 时，底面各点下沉量：

```
下沉量 = 到耳轴的水平距离 × sin(θ)
座圈中段（0.7 m）  → 0.15 m @12°
座圈后缘（1.5 m）  → 0.31 m @12°
```

所以「塔体平底」压在「座圈平顶」上，只有三种结局：

1. **留缝** ≥0.31 m（看着悬空）
2. **抬高 + 加东西遮**（颈柱 / 锥座 / 裙边 —— 越遮越大，用户都否了）
3. **不抬高** → 穿模（实测 +12° 几千对相交面）

**真正的摇摆炮塔靠圆弧关节，但它要求「塔体比座圈短」**：AMX-13 的上部塔体只有座圈直径那么大，
底面能切成一条完整圆弧。我们的比例相反——要切出 R≥1.45 m 的弧，弧最低点会落到甲板以下 0.55 m；
取 R=0.85（贴座圈）则前后 0.6 m 塔体被整块切掉。**两条都不通。**

**结论**：1:1 跟随在这个模型比例下做不出好看形状。要么接受 25% 微动（当前），
要么换设计（缩短塔体 / 缩小射界到 ±5° 以内 / 改成只有炮盾+炮座俯仰）。
