## 3. 模型链路（重做模型看这里）

### 生成（Lux3D，`G1` / `faceCount=60000` / `style=photorealistic`）

每台车**两份**，提示词在 `ArtSource/Lux3D/_prompts.txt` 的基础上加两句（"炮塔独立/甲板平整"）：

| 文件 | 提示词要点 |
|---|---|
| `{name}_hull_only.glb` | `HULL ONLY ... no turret, no gun: bare flat rectangular hull roof deck with a round recessed turret ring opening in the middle` |
| `{name}_turret.glb` | `TURRET ONLY ... isolated part, no hull: ... flat circular bottom base where it sits on the hull` |

### 拼装（`work/assemble_tank.py`）

```powershell
blender -b --python work\assemble_tank.py -- <name> <车长> v4
# 例：blender -b --python work\assemble_tank.py -- main 8.6 v4
```

自动做这些：
1. 车体按车长归一化（长轴→Y、水平居中、底面贴地）
2. 俯视高度图找甲板高度；甲板缺失的连通块按「圆度 + 靠中间」打分，认出**炮塔环**（圆心+半径）
3. 车体零件里沿车长最长的两块 = **履带**，单独拆出
4. 炮塔：5° 扫一圈找「伸得最远、尖端又细」的方向 = **炮口**；转到 **Blender −Y**（= Unity +Z）；量底部圆，缩放到环半径 **1.04 倍**，下沉 0.06 m
5. 沿 Y 扫横截面宽度，第一次 >1.1 m 处 = 炮盾，**把炮管切出来**（转轴取切面附近炮管顶点的均值）
6. 导出 `Assets/Models/Vehicles/Split/{name}_{hull,turret,barrel,tracks}_v4.fbx`

### 贴图与材质

```powershell
python work\extract_textures2.py ArtSource\Lux3D\<name>_hull_only.glb  <name>_hull_v4
python work\extract_textures2.py ArtSource\Lux3D\<name>_turret.glb      <name>_turret_v4
```
然后在 Unity 里建 Standard 材质（color 0.70 / glossiness 0.12 / metallic 0.05），填进 VehicleDef。

### VehicleDef 里新增的字段

```
useSplitTurret        用不用拆件炮塔
modelTracksPrefab     履带 prefab（模型自带 / 生成的总成）
modelTrackWellRef     原模型履带，只用来量"履带槽"尺寸（程序生成履带时用）
modelTurretMaterial   炮塔自己的材质（和车体贴图不是同一张）
modelBarrelPrefab     炮管 prefab（单独做俯仰）
modelBarrelPivot      炮管转轴（炮盾中心，车体局部）
modelTurretMeshOrigin 炮塔网格原点（改转轴时用来反偏移，保持外观位置不变）
autoTurretWellPatch   自动补炮塔井（现在全关：车体本来就没洞）
```

## 4. 关键教训（都是今天踩的，别再踩）

| 坑 | 现象 | 修法 |
|---|---|---|
| **Blender +Y = Unity −Z** | 炮管转到"车头"结果指车尾 | FBX 轴转换是 `(x,y,z) → (x,z,−y)`；要朝 Unity +Z 就得对齐 **Blender −Y** |
| **FBX 根节点带 100 倍缩放 + −90°X** | 手算顶点坐标差 100 倍；程序生成的物体被放大 100 倍 | 一律用**渲染包围盒**（`Renderer.bounds`）换算，不要手推 `mesh.vertices`；生成物挂到**车体**而不是履带节点下 |
| **`Awake` 里读不到刚 AddComponent 后赋的字段** | 走了错分支，改动"看起来没生效" | 这种初始化放 **`Start()`** |
| **`VehiclePhysics.Start()` 会调 `ApplyDef()`** | 我在 `Attach` 里设的 `groundClearance` 被写回 0.5 → 车悬空 | 加 `modelSitsOnGround` 标记，`ApplyDef` 按标记给值 |
| **`part_split` 的零件会互相粘连** | 轮子上粘着一块履带，轮子一转那块履带跟着转 | 见第 8 节；Blender 里按"离轮心距离"删面可清洗，但会掉细节 |
| **`part_split` 的零件位移可能被烘进网格** | 几个轮子共用同一个原点 → 绕公共中心转 | 每个轮子加**枢轴**（放在网格包围盒中心），转枢轴 |
| **PowerShell 改 .cs 会写坏 UTF-8** | 中文注释变 GBK，整个文件 invalid UTF-8 | **只用 `edit` / `write` 工具改源码**；写坏了 `git checkout -- 文件` |
| **改完 .cs 立刻跑** | 跑的是旧程序集（改动"没生效"的常见原因） | `AssetDatabase.Refresh` + `RequestScriptCompilation`，等 20~25 秒再执行 |
| **打包会断 MCP** | 编辑器主线程被占，请求超时 | 打包前保存；断了就 `mcp_switch_off/on` |

## 8. 履带：三条路线都试过了（**别再重复试错**）

目标：**负重轮原地转 + 履带板往前跑，速度一致（`履带线速度 = ω × R`）**。

### 方案 A：用模型自带的履带，只滚贴图（**当前采用**）

- 做法：`TrackScroller` 按面朝向拆 submesh（轮子侧面用深灰金属、其余贴滚动纹路），按车速滚 UV
- 优点：**外观最好**（Lux3D 生成的真实履带细节都在）
- 缺点：**轮子不转**；而且模型 UV 是乱的，得自己重算 UV 才有方向感
- 文件：`Assets/Scripts/Units/TrackScroller.cs`

### 方案 B：让 Lux3D 单独生成「履带总成」，再 part_split 拆成轮子+履带

- 生成提示词（效果好，**这一步是成功的**）：
  `TRACK AND RUNNING GEAR ONLY ... two continuous caterpillar track belts ... each belt wrapping around six separate large road wheels ... visible gap between the wheel rims and the inner face of the belt`
- 拆件结果：20 个零件（3 块履带板 + 约 10 个单轮 + 3 个"双联轮" + 7 个螺栓）
- 脚本：`work/build_tracks.py`（分类、切双联轮、每轮原点搬到几何中心）
- **卡住的地方（用户实测到的两个毛病）**：
  1. **切双联轮时切面残留履带碎片** → 轮子转的时候带着一小块履带一起转
  2. **FBX 导出把对象位移烘进网格** → 几个轮子共用原点，绕公共中心转
- 修法（部分有效）：`TrackAssembly.Collect()` 里给每个轮子加**枢轴**；Blender 里按"离轮心距离 > 1.3R"删面可清洗碎片，但会掉细节
- 结论：**能转、但外观比 A 差**，而且需要人工确认每个零件是什么

### 方案 C：按车体履带槽尺寸程序生成轮子 + 跑道形履带

- 做法：拿原模型履带只当"尺子"量出履带槽包围盒（主战：`4.153 × 1.915 × 8.286`），按这个尺寸造 6 个圆柱负重轮 + 一条跑道形履带带（两段直线 + 两端半圆，UV 沿路径铺）
- 优点：轮子和履带是**两个独立物体，不可能粘连**；轮子绕各自枢轴转、履带按路径滚，速度一致
- 缺点：**外观明显是"程序员美术"**，用户评价"太难看了"
- 文件：`Assets/Scripts/Units/TrackAssembly.cs` 的 `BuildFitted()`

### 如果还要继续做，建议

- 外观优先 → 用 A，接受轮子不转；想加"转"的错觉，可以在轮子上叠一层**转动的轮毂盘**（小圆柱 + 辐条贴图），只盖住轮心那一小块
- 真要"好看 + 真转" → 只能**手工建一套履带总成**（6 个负重轮 + 1 条履带带）对齐到方案 C 量出来的槽尺寸，然后逐台调；或者用 Blender 手工从模型上把轮子切干净
- **不要再试**：整台车生成后 part_split 切炮塔（会留破口）、loose parts 拆轮子（Lux3D 是面片汤，拆出 1000+ 块）
