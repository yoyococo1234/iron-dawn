## 3. 几个关键实现点（改之前先看）

### 3.1 移动轴为什么不能直接用 `Input.GetAxis`

旧 Input Manager 的 `Vertical/Horizontal` 轴是**项目设置里写死的**，运行时改不了，
所以「WASD 可改键」必须绕开它：`Bindings.AxisV/AxisH` 直接读键算 -1~1，
`VehiclePhysics.ThrottleInput/SteerInput` 和飞机的油门/横滚都改成读这个。
**代价**：手柄和方向键不再默认可用（要的话在按键设置里绑）。

### 3.2 「第一次出场」不能扣命

海空单位开局就建好了 `UnitState`，但要等解锁才出场。如果走普通复活路径，
`UpdateRespawns` 会 `lives--`，等于开局白扣一条命。
所以加了 `firstSpawnPending`：**必须在 `respawnAt` 判断之前处理**（待出场单位的 `respawnAt` 是 -1）。

### 3.3 人数配置只算 AI

`MatchSettings.AiCount(team)` 是 AI 台数；玩家自己另算一台。
`BuildUnits` 里 team0 先插玩家（index 0），AI 从 index 1 开始编号，
所以「我方5号」这种播报不会和「你」撞号。

### 3.4 AI 瞄准误差会把瞄准点压到地下（本次踩的坑）

加了随机误差后 AI **一炮都不放**。原因：误差的 Y 分量把瞄准点压到地面以下，
`HasLineOfSight` 从炮口打向那个地下点 → 命中地形 → 判定"被挡住" → 永远不开火。
修法：误差之后把 `aim.y` 夹到 `地形高度 + 0.9 m` 以上。

### 3.5 改键的冲突检测

`Bindings.TrySet` 遍历整张表，撞到别的动作直接返回 false 并带出那个动作名；
界面显示「X 已经被「开火」占用，换一个」并播拒绝音。**只拦键盘，鼠标键写死不改。**

## 4. 「多加两个 AI 舰艇会怎么样」—— 实测回答

把每方舰艇从 1 调到 3（也就是各多 2 艘），解锁时间设 0 直接开局全上：

| 指标 | 结果 |
|---|---|
| 场上载具 | 14 台（我方 7 + 敌方 7） |
| 按类型 | 舰艇 6 · 战斗机 3 · 主战 3 · 重装 2（和配置完全一致） |
| **FPS** | **平均 130.1 / 最低 125.4**（12 秒采样） |
| 报错 | 0 |

**结论：性能完全不是问题**（多 4 台载具几乎不掉帧）。要注意的是玩法层面：

1. **出生点**：船的出生要求船体中心 ±10 m 五个点都 ≥3 m 深，`FindSeaSpawn` 会沿出生线扫，
   扫不到就全图找最深的空水域。6 艘船实测都能正常出生，没有叠船。
2. **海战会变主战场**：炮艇 5 万血 + 舰炮 1200 m 射程，船多的时候港口区会很热闹。
3. **陆战玩家会被舰炮压制**：船打不到城区深处，但滩头/开阔地会被点名。
4. **AI 换车经济**：船贵，AI 钱不够时会在复活点干等（`UpdateRespawns` 里攒钱逻辑）。

想试就在「游戏调整 → 舰艇」里加，加完下一局生效。

## 5. 还没验证 / 已知限制

1. **改键的点击路径没法自动化测**：MCP 的 `script-execute` 改不了 `Input.mousePosition`，
   也没法注入真实按键事件。已验证的是：面板渲染正确、`Bindings.TrySet` 的冲突逻辑、
   `PlayerPrefs` 读写。**下次真机点一次「按键设置 → 前进 → 按 K」确认。**
2. **AI 手感需要实机微调**：三档已经给了，但「普通」到底够不够弱要人打一局才知道。
   实测数据（150 m，一台敌方 AI 打玩家 12 秒）：普通档 1 发 1 中、掉血 2735（满血 8568）。
   觉得还太强就选「轻松」（瞄准误差约 ×2、开火距离 ×0.45）。
3. **初始金币 200 = 主战坦克的价格**，买完主战就没钱了。想宽松点自己在「游戏调整」里加。
4. 车库/商店仍然只能鼠标操作（键盘导航没做，这次没在需求里）。
5. `AIDef.asset` 是**死资产**——`VehicleAI` 根本没读它，参数都在组件上。要么删，要么以后接上。
