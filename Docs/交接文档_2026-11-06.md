## 1. 今天做完的

### A. 船尾泡沫尾迹（新文件 `Assets/Scripts/Units/SeaFoamWake.cs`）

昨天的问题是「船尾白色浪花没做」——Crest 的 `SphereWaterInteraction` **只往动态波浪模拟里写数据**（把水推开），
泡沫是另一张模拟图（`LodDataMgrFoam`），要单独的输入。

做法：把船尾走过的点连成一条**飘带（ribbon）**，用 `Crest/Inputs/Foam/Add From Vert Colours` 着色器 + `RegisterFoamInput` 组件写进泡沫模拟。

| 参数 | 值 | 说明 |
|---|---|---|
| `sampleSpacing` | 2.2 m | 船每前进这么多米记一个点 |
| `maxSamples` | 70 | 尾巴最长 70 × 2.2 ≈ 154 m |
| `lifetime` | 6.5 s | 点的存活时间 |
| `widthMul` | 1.6 | 飘带初始半宽 = 船宽 × 1.6 |
| `spread` | 1.1 m/s | 每秒向外扩散（尾迹张角） |
| `peak` | **0.035** | 每帧写入量，见下面「数值为什么是这个量级」 |
| `edgeJitter` | 0.18 | 边缘毛刺，避免笔直的带子 |

横截面 4 列顶点（左外 / 左内 / 右内 / 右外），外侧顶点色给 0，边缘自然化开。
顶点色 R 通道 = 泡沫强度（着色器就是 `return _Strength * col.r`）。

`SimFoam.asset` 的 `_foamFadeRate` 从 **0.8 改成 0.35**，尾迹从 ~40 m 拉长到 ~150 m。

挂在 `SeaBuoyancy.Start()` 里自动加（只有 `Domain.Sea` 的载具才会有 `SeaBuoyancy`）。

### B. 波形：ShapeGerstnerBatched → ShapeFFT

`CrestOcean/FFTWaves`（新 GameObject）挂 `ShapeFFT`，旧的 `CrestOcean/GerstnerWaves` 保留但 **enabled = false**（方便回退）。

| 参数 | 值 |
|---|---|
| `_spectrum` | `Assets/Crest/Created/WaveSpectrum.asset`（复用原来那个） |
| `_overrideGlobalWindSpeed` | true，`_windSpeed` = **18 km/h**（= 5 m/s） |
| `_overrideGlobalWindDirection` | true，`_waveDirectionHeadingAngle` = 45° |
| `_resolution` | 256 |

**为什么要 override 风速**：OceanRenderer 的全局风是 `_globalWindSpeed = 2.5`（km/h，几乎无风），
直接继承的话 FFT 几乎不起浪。注意 `ShapeFFT.WindSpeed` 属性返回的是 **m/s**（内部 `_windSpeed` 存 km/h，除以 3.6）。

效果对比（截图在 `work/shots/`）：
- `sea_gerstner/` 旧的：海面几乎是平的，远处没细节
- `sea_fft/` 新的：满屏小碎浪 + 白色浪尖，一直到天边都有细节

### C. 水面反射：用 Crest 自带的平面反射

昨天是「手搓平面反射矩阵算错，撤掉了」。**不用手搓**——Crest 4.23 自带 `OceanPlanarReflection`：

1. 主相机（Main Camera）挂 `Crest.OceanPlanarReflection` 组件
2. `Assets/Crest/Materials/Ocean.mat` 勾 `_PlanarReflections`（同时 EnableKeyword `_PLANARREFLECTIONS_ON`）
3. 强度：`_PlanarReflectionIntensity` 0.85、`_PlanarReflectionNormalsStrength` 1、`_PlanarReflectionDistanceFactor` 0.15

截图：`work/shots/sea_planar_boat/02_side.png` 能看到船体在水里的倒影。

## 2. 踩过的坑（今天新踩的，很重要）

1. **泡沫模拟是累加器，顶点色必须给 0.01~0.05 量级**
   稳态浓度 ≈ 每帧写入量 / (`_foamFadeRate` × 帧时长) ≈ 写入量 × 37.5。
   第一次给 `_Strength = 0.5`，整条尾迹饱和成一条纯白带；改成顶点色 0.035 才有纹理、有边缘、会淡出。

2. **飘带顶点是世界坐标 → 承载它的 GameObject 必须留在原点**
   中途想「把飘带物体挪到船上，让 Crest 的位移校正在船的位置采样」，结果顶点被再乘一次物体矩阵，
   整条尾迹直接飘到 900 米外（完全看不见）。要动位置就把顶点改成局部坐标，两者只能选一个。

3. **`RegisterLodDataInputBase` 会 `buf.DrawRenderer(_renderer, ...)`，材质要写在 `renderer.sharedMaterial`**
   用 `.material` 会实例化一份，基类读不到。

4. **验收截图台要等 Crest 重建 LOD**
   相机一跳到新位置，Crest 的泡沫/LOD 数据要跑几帧才在新区域累积起来。
   立刻 `cam.Render()` 拍到的是「空的泡沫」，看起来像功能坏了。
   正确写法：机位设好 → `for (i<12) yield return null;` → `WaitForEndOfFrame` → 再拍。
   （`DevSeaShots.RunAroundBoat` 就是这么写的，可以照抄。）

5. **换波形会连带影响**：船的升沉/俯仰由 `SeaBuoyancy` 采样水面得到，浪一大船会晃得更明显；
   白色浪尖也变多（泡沫模拟的 wave foam）。这是预期内的，但如果用户觉得晃得过头，调 `SeaBuoyancy.heaveScale / tiltScale`。
