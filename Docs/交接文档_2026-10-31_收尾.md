## 3. ⚠️ 没修好的：炮塔拆件后车体上的黑洞

### 现象

炮塔从车体上切开后，**车体顶面在炮塔后方露出一个不规则黑洞**（用户红圈标出的那块）。
炮塔转开时更明显。

### 根因（已定位清楚）

1. Lux3D 的模型是**面片汤**（一台车 5000+ 个独立面片，没有语义部件）。
2. 我用 `part_split` 拆出 6 块后，把「炮塔」那块从车体上**拿走**，
   车体顶面就留下一个**不规则的开口**。
3. 车体是**空心壳**，所以那个开口看到的是**内壁**——表现就是一片黑。
4. 开口的位置和形状**不等于**炮塔底部截面：炮塔那块包含长炮管，
   重心被往前拽，所以我按"炮塔底部一圈顶点"算出来的圆盘**位置偏前、半径偏小**，盖不住。

### 试过的三种办法（都失败）

| 尝试 | 结果 |
|---|---|
| ① 用**迷彩材质**的大圆盘盖住 | 半径太大，像一块板子叠在车上，很丑 |
| ② Blender `fill_holes(sides=0)` 给车体补面 | 面片汤的开口不是干净边界环，补不准；而且黑的是内壁，补面治不了 |
| ③ 运行时按「炮塔底部顶点」算圆盘 | **就是当前这版**——位置偏前、半径 1.59 m，还是盖不住（用户截图证明） |

### 下一步建议（按可行性排序）

1. **改成方块盖板，别用圆盘**：在 Blender 里算「车体在切割面附近的边界顶点」的 XY 包围盒
   （不是炮塔的），导出成一个矩形尺寸，Unity 里用一块**深灰方块**盖住。
   方块比圆盘更容易覆盖不规则形状，也更容易对准。
2. **直接从车体侧算**：在 `build_turret.py` 里，分离炮塔后遍历车体的**边界边**
   （`len(e.link_faces)==1`），只取高度在切割面 ±0.3 内的那些，算它们的 XY 包围盒 ——
   这就是洞的真实范围。把它写进 `turret_pivots.txt` 一起给 Unity。
3. **回退方案（最稳）**：放弃炮塔旋转，用**整体模型**（外观完全没问题），
   开火方向限制在车头 ±40°，观感上也不违和。`VehicleDef.modelTurretPrefab` 留空即自动回退。
4. **重新生成模型**：给 Lux3D 的提示词里明确要求「turret as a separate detachable part」，
   再拆一次，部件语义可能更干净。

> 我推荐 **2 → 1**，实在不行用 **3** 兜底。

## 6. 今天踩的坑（都别再踩）

| 坑 | 现象 | 修法 |
|---|---|---|
| **数据资产没序列化进场景** | 打包后车库列表空、资源点不产金、出兵线错 | 编辑器脚本里把 `MatchDef`/`BattlefieldDef` 显式赋给组件；`MatchManager.Start` 加自检日志 |
| **FBX 根节点自带缩放/上轴修正** | 模型缩成 1/100 还歪着 | 在原值基础上**叠加** `modelYawOffset`/`modelScale`，不要直接覆盖 |
| **命中盒按世界 AABB 算** | 车一转向命中盒就横过来 | 按网格局部包围盒的 8 个角换算 |
| **`Object` 二义性** | script-execute 报 CS0104 | 写 `UnityEngine.Object` |
| **本类有 `Physics` 同名属性** | `Physics.RaycastAll` 解析成属性 | 写 `UnityEngine.Physics` |
| **`GUI.skin` 只能在 OnGUI 内用** | 在 Awake 建 GUIStyle 抛异常，HUD 全不显示 | 样式延迟到第一次 OnGUI |
| **`Dictionary.Remove(null)`** | 首次部署抛 ArgumentNullException | 先判空 |
| **`Awake` 时 `team` 还是 0** | 敌机被染成我方蓝色 | `SetTeam` 里重新上色 |
| **PowerShell 覆盖写 .cs 文件** | 中文注释变 GBK，整个文件 invalid UTF-8 | **不要用 pwsh 的 Set-Content 改源码**，用 edit 工具；写坏了 `git checkout -- 文件` |
| **炮塔转轴用包围盒中心** | 被长炮管拽偏，转起来偏移 | 用**顶点重心** |
| **飞机机头朝向** | 战斗机是 −Z（要转 180°），攻击机是 +Z（不用转） | 一台一台单独验证，别批量套同一个值 |
| **打包会断 MCP 连接** | 编辑器主线程被占 | 打包前先保存；断了 `unity-mcp-cli close` + `open` 重启 Unity |
| **改完 .cs 立刻在同一个调用里跑** | 跑的是旧程序集 | 先 `AssetDatabase.Refresh`，等编译完再执行业务 |

**重做拆件的完整流程**：
1. `upload_asset` 上传 `ArtSource/Lux3D/{id}.glb`
2. `lux3d_part_split`（wait=false）→ 轮询 `lux3d_get_task` → 拿结果 URL
3. 下载成 `ArtSource/Lux3D/{id}_parts.glb`
4. `blender -b --python work/build_turret.py`
5. `python work/write_pivots.py`
6. Unity 里跑菜单 ②
