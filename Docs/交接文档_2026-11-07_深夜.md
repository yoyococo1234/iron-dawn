## 1. 今天做完的

### A. 地形（花的时间最多，也是最有价值的一条）

**"沟壑"的真凶**（查了三轮才定位）：

| 现象 | 真因 | 修法 |
|---|---|---|
| 地图上十几条细长弧线，像地裂 | `CarvePass` 用反距离加权混合路基高度，但权重在 `距离 = W` 处**突然归零** → 每条路段外形成一圈细折痕 | 权重在 `0.6W~W` 之间平滑淡出 |
| 同样位置的折痕 | `PlainField / LowHillField / MountainField` 用 `Mathf.Clamp` 硬压上下限，**被压住的边界是一条等值线**，法线在那里折断 | 换成 `SmoothClamp()`（渐近贴回，不折角） |
| 高频毛刺 | 1~2 格窄特征 | 高度图加 3×3 均值平滑（边界夹取索引，保证四块地形接缝连续） |
| 山脚一圈平滑带 | `HeightWorld` 里"公路上压噪声"的掩码（`1 - 0.9*road`） | 公路都没了，直接去掉 |

**怎么验证的（这个方法以后继续用）**：把高度图渲成**山体阴影图**（1024×1024，
`0.55 - dx*0.35 + dz*0.25` 当灰度）导出 PNG，折痕在阴影图上一眼就能看见 —— 比在游戏里找快得多。
修完：高度图"尖刺格"（拉普拉斯 > 0.15 m）**22791 → 0**。

## 6. 今天踩的坑（血泪，别再踩）

1. **查地形缺陷要渲山体阴影图**，不要在游戏里找 —— 阴影图上一眼就能看见折痕，
   而且能区分"几何折痕"（阴影图里有）和"贴图问题"（阴影图里没有）。
2. **`Mathf.Clamp` 会在地形高度场里留下等值线折痕** —— 地形函数里一律用 `SmoothClamp`。
3. **反距离加权混合，权重必须在边界处平滑到 0**，否则就是一圈折痕。
4. **改 `.cs` 中文注释的文件别用 PowerShell 读写**（`Get-Content`/`WriteAllLines` 会毁编码，
   我这轮就把 `MatchHUD.cs` 写坏了，最后用 `git cat-file` 取回原始字节才救回来）。
   要改就先用 `read` 工具读、再用 `edit` 工具改。
5. **测试弹丸类武器时注意 `Time.timeScale`**：开局封面把它压成 0，弹丸根本不动，
   会得出"打不中"的假结论。测之前先 `Destroy(GameStartScreen)` + `Time.timeScale = 1`。
6. **`Fire1` 默认绑定 `left ctrl`**（Unity 模板），所以加了 Ctrl 锁定之后一按 Ctrl 就开火。
   已把 `Fire1` 的 left ctrl 去掉，开火改用显式 `Input.GetMouseButton(0)`。
7. **炮口节点挂在 `Model` 上**，而 `SeaBuoyancy` 只动 Model → 任何用炮口位置算出来的
   准星/瞄准角都会随浪抖。要么用船体根部算，要么给 Model 加稳定器。
8. **阵亡是 `SetActive(false)` 不是销毁**：挂在载具上的"持续输出型"组件（尾迹、作用球）
   必须在 `OnDisable` 里撤掉，否则会一直往模拟里画东西（沉船后海面留一坨白泡沫）。
9. **`app_launch` 起 Unity 后要检查弹窗**，恢复备份对话框会挡住 MCP 一切调用。
