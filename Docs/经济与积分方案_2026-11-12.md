# 经济 / 数值 / 胜利条件方案（v1 · 待过目）

> 2026-11-12 · 铁皮黎明（Tank3D）
> 依据：**现有代码里的真实数值**（不是拍脑袋），逐项列在 §1，方便你对照着砍。
> 参考的先贤案例：**BF 征服（票数衰减）**、**英雄连 CoH（胜利点 VP + 落后方资源加成）**、**战争雷霆（战区占点分 + 出生点 SP）**、**坦克世界（占领进度条）**。

---

## 0. 一句话

**金币只决定"你开什么"，积分（VP）决定"谁赢"。** 占点从"只为挣钱"升级成"直接得分"，胜负由 VP 累计到 1500 或 15 分钟到点比分数决定；命数退成兜底。

### 1.2 金币（`MatchManager` + `MatchDef`）

| 项 | 现状 |
|---|---|
| 开局金币 | 菜单设置，默认 **200** |
| 占点收入 | 每 10 s，每点 5（侧翼）或 15（山/城区/港口/开阔），**给全队每人** |
| 击杀奖励 | 目标价 × **0.4** |
| 助攻 | 配置有 0.2，**代码没实现** |
| 部署花费 | 载具原价（钱不够最便宜的免费） |
| 修理 | 1 金 / 1% HP；补弹 20 |
| 命数 | 每人 3（今天已改成首次不扣） |
| 时长 / 据点 | 15 min / 6 个点 |

### 1.3 现在的问题（这就是要改的理由）

1. **开局 200 金只够出一台车**，死一次就基本破产 → 经济不是"策略"，是"卡脖子"。
2. **炮艇 180 金 7003 血**，性价比碾压所有陆战载具（HP/金 38.9 vs 主战 6.0）。
3. **占点只为钱**：占了不加分，赢了不加分，胜负只看"命数用完 / 时间到比命"。
4. 金币和胜负完全脱钩 → 打钱和打赢是两件事，玩家不知道该干什么。

## 2. 设计目标

1. **占点必须有胜负价值**（不只是收入）。
2. **金币 = 战术资源**（决定你开什么），**VP = 战略目标**（决定谁赢），两者不互通。
3. 一局 **12~15 分钟**，落后方有翻盘窗口（反滚雪球）。
4. 每台载具都有出场理由 —— 不出现"唯一最优解"。

---

## 3. 胜利点（VP）规则

### 3.1 计分表

| 事件 | VP | 说明 |
|---|---|---|
| **持有据点** | **+1 VP / 2 s / 每点** | 6 点全占 = 3 VP/s；双方各持 3 点 = 各 1.5 VP/s |
| 首次占领（从非我方变成我方） | **+25** | 一次性，鼓励抢点 |
| 击杀 | **+10** | 与金币奖励解耦 |
| 助攻 | **+4** | 需要先实现助攻统计 |
| 被击毁 | 0 | **不扣分**（负反馈太强，参考 BF 也不扣个人分） |

### 3.2 胜负判定

- **先到 1500 VP 获胜**；
- 15 分钟到点：**VP 高者胜**；同分 → 比剩余命数；再同 → 判我方胜（现状逻辑保留）。

### 3.3 数值校验（为什么是 1500 / 15 min）

| 局面 | VP 速率 | 到 1500 用时 |
|---|---|---|
| 6 点全占（碾压） | 3.0 /s | **8.3 min** |
| 4:2 领先 | 2.0 /s | 12.5 min |
| 3:3 拉锯 | 1.5 /s | 16.7 min → **打满 15 min 比分数** |

即：碾压局 8 分钟结束（不拖），均势局正好用满 15 分钟。**击杀分只是补充**（15 min 打 30 个人头才 300 分，占比 20%），保证"占点为主、击杀为辅"。

### 3.4 反滚雪球（推荐，参考 CoH）

- 落后方（VP < 对方 × 0.6）**占点 VP ×1.3**；
- 领先方（VP > 对方 × 1.5）**占点 VP ×0.85**。
- 效果：把"一边倒"的垃圾时间压缩，但不会让领先白打。

## 4. 金币经济

### 4.1 收入

| 来源 | 数值 | 说明 |
|---|---|---|
| 开局金币 | **800** | 能出主战 + 一次复活，不用一开局就省吃俭用 |
| 占点收入 | 侧翼 5 / 核心点 15，每 10 s，**全队每人** | 现状保留（核心点=山/城区/港口/开阔） |
| 生存补贴 | **+3 / 10 s**（活着的玩家） | 抑制挂机；也奖励"活着占点" |
| 击杀奖励 | 目标价 × **0.45**（上限 200） | 现状 0.4 |
| 助攻 | 目标价 × **0.2** | 需实现 |
| 金币上限 | **3000** | 防囤积 |

### 4.2 支出

| 项 | 数值 | 说明 |
|---|---|---|
| 部署 | 载具价 × **复活系数** | 见下 |
| 复活系数 | 1 + 0.15 × 已复活次数，**上限 1.6** | 越死越贵，鼓励保命（参考 WT 的出生点递增） |
| 中途换车（G） | 载具价 × **1.2** | 惩罚反复换车刷最优解 |
| 修理 | 1 金 / 1% HP | 现状 |
| 补弹 | 20 | 现状 |
| 钱不够 | 最便宜那台**免费**（现状保留） | 保证"有命就能复活" |

### 4.3 一条经济曲线（主战玩家，均势局）

```
开局 800
→ 出主战 220 → 剩 580
收入：持 3 点（2 侧翼 5 + 1 核心 15 = 25 / 10s = 150 金/分钟）
      击杀 2 台/分钟 ≈ 2 × 90 = 180 金/分钟
      生存补贴 18 金/分钟
      ≈ 350 金/分钟
→ 死一次：复活成本 220 × 1.15 ≈ 253 → 约 45 秒回本，节奏刚好
→ 打满 15 分钟理论毛收入 ≈ 5000，实际受 3000 上限约束 → 后期要"花掉"（修理/换车）
```

## 5. 载具重定价（让性价比收敛）

| 载具 | 现价 | **建议价** | 理由 |
|---|---|---|---|
| 轻坦 | 160 | **140** | 便宜灵活，开局抢点首选 |
| 主战 | 200 | **220** | 万金油，微涨 |
| 重装 | 220 | **260** | 1600 HP + 420 单发，正面最强 |
| **炮艇** | 180 | **320**（并把 HP 7003 → **4500**） | 现在性价比碾压：HP/金 38.9 vs 主战 6.0 |
| 战斗机 | 160 | **180** | 制空价值高（1600 m 空空导弹） |
| 攻击机 | 200 | **240** | 对地最强（520 反坦克 + 750 炸弹） |

**HP/金 收敛后**：轻坦 5.7、主战 5.5、重装 6.2、炮艇 14.1（海上唯一选择，仍偏高但可接受）、战斗机 1.7、攻击机 1.9。
> 飞机 HP/金 天生低，但它的价值在**速度 45 + 400 DPS 机炮**，用"机动性"换"血条"，不靠血条定价。

**域解锁配套**：陆战常开、海战 **90 s**、空战 **180 s**（现状 3 min 保留，可调）。

## 8. 需要你拍板的三件事

1. **VP 是"双方都涨"（赛跑）还是"零和"（只有领先方涨、落后方掉）？**
   我推荐**赛跑**：不会出现"两边都不动"的死局，玩家永远有事做。
2. **炮艇：涨价到 320 还是削血到 4500？** 我推荐**两个一起做**（320 金 + 4500 血），否则海上永远是炮艇一家独大。
3. **目标分 1500 / 15 分钟** 这个尺度行不行？如果想让节奏更快，可以 1200 分（碾压局 6.7 min）。

> 你点头之后我按 P0 → P1 的顺序做，每期出包给你验。
