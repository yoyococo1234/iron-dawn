## 0. 一句话现状

**轻坦履带已经不是"在烂网格上打补丁"，而是按尺寸重新生成：环带 + 一节一节履带板 + 主动轮（带齿）+ 诱导轮 + 负重轮 + 托带轮。干净、可控、能转。重坦/主战没动。**

## 1. 根因（这次是证据定位，不是猜）

### 1.1 致命的一条：FBX 没勾 Read/Write Enabled

`Assets/Models/Vehicles/Split/light_tracks3_clean.fbx` 的 `isReadable = 0`。

后果是**整条链路静默失效**：

| 调用 | 结果 |
|---|---|
| `mesh.vertices` | 抛 `Not allowed to access vertices ... (isReadable is false)` |
| `CollectBelts()` | `BuildBelt` 抛异常 → **`_belts.Count == 0`**（运行时 dump 实测：`belts=0`） |
| `TrimRadial()` / `ShiftMesh()` | 抛异常 → 轮子不纠偏心、不截尖刺 |
| `RebuildEndWheels()` | 因为 `_belts.Count == 0` 直接 return |

也就是说：**履带一条都没被接管**，不转、不清理、不重建。画面上只表现为"履带有点怪"，很容易误判成美术问题。

对照：旧的 `light_tracks3.fbx`、`main_tracks3.fbx`、`heavy_tracks3.fbx` 都是 `isReadable = 1`，**只有 Blender 重新导出的这条中招**。

**已修**：`ModelImporter.isReadable = true` 重导 + 代码里加 `CheckMeshesReadable()` 硬闸（不可读就 `LogError` 并停手，不再静默）。

### 1.2 那条履带网格本身也救不回来

顶点到中心线的偏移是**连续分布**（实测，单位米）：

| p50 | p75 | p90 | p97 | p99 |
|---|---|---|---|---|
| 0.11 | 0.22 | 0.34 | 0.50 | 0.56 |

没有阈值能把"履带板"和"内侧那团碎面"分开 —— 之前 5 层启发式补丁（TrimToXBand / p97 带宽 / 轮轴排除 / 压平碎片 / 端部轮重建）注定互相打架。打开读权限后跑一遍，补丁的副作用立刻现形：

- **端部轮重建**判据是"轮子列表里 z 最外 8%"，但轻坦真正的主动轮在 `static_clean` 里、**不在列表里** → 把最前面两个**负重轮**换成了大圆盘（`wheel_06/07` → `Sprocket`）；
- **按半径截断**用"中位半径 × 1.25"，而轮盘顶点往圆心密集分布，中位半径只有外径 0.78 → 把 0.43 m 的负重轮切成 **0.35 m**；
- 履带环高 1.41 m、负重轮只有 0.88 m，顶上那段悬空 0.5 m，**没有托带轮撑着**。

| `Assets/Data/Vehicles/Vehicle_land_light.asset` | 打开程序化履带：span 1.74 / band 0.44 / loop 6.80×1.15 / 负重轮 R 0.40 ×5 |
| `Assets/Scripts/Dev/DevTankShots.cs` | **新**：验收截图台（见第 4 节） |

### 程序化履带怎么长的

```
stadium 环（两直段 + 两个半圆）        中心线 R = loopHeight/2 - 板厚/2
  ├─ 4 条面：外 / 右 / 内 / 左          每条面独立顶点，棱角是硬的
  ├─ 每 3 个环做一次"凸起"              → 侧影上就是一节一节的履带板
  ├─ 主动轮（前端，12 齿）+ 诱导轮（后端）
  ├─ 负重轮 ×N（带轮缘台阶 + 凸出轮毂）
  └─ 托带轮 ×2（撑着上段履带，不再悬空）
```

- 顶点 UV2 直接按弧长写入 → 复用现有 `Tank/TrackBelt` GPU 顶点动画（`_PathArr` 255 点）；
- 轮子走 `TrackAssembly` 原来的自转逻辑（ω = v/R，差速转向照旧）；
- 材质：履带深钢色、轮子略浅，侧视分得开。

## 5. 给下一个人

- **先看 `dump.txt`，再看图**。履带这类问题，运行时数据（`belts=?`、`gpu=?`、偏移分位）比截图快十倍。
- **Unity 的 `mesh.vertices` 抛异常时不会中断程序**，只会让那段逻辑静默失效。凡是读网格的代码，先 `if (!mesh.isReadable)` 吼一声。
- **打包前确认编辑器停在正式场景**（`Map_Battlefield.unity`），否则 `BuildPlayer` 会返回 Unknown。
