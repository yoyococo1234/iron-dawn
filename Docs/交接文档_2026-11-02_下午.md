## 2. 这一轮做完的事

### 2.1 新模型：车体和炮塔**分别生成**（用户提的思路，是这一轮唯一真正有效的突破）

老路子的死结：Lux3D 生成的整台坦克，炮塔是从车体里"挖"出来的，**切哪儿都会在车体上留一个炮塔大小的洞**，补板怎么放都不对（凸出来 / 凹进去 / 露毛刺）。这一轮我在这上面反复折腾了两个多小时（`split_turret_v2.py` / `split_turret_v3.py` / `fill_turret_well.py`），全部失败。

用户提出「车体和炮塔分别生成」之后一次就通了：

| 任务 | 内容 |
|---|---|
| 4573842 | 无炮塔车体（主战）：甲板整块实的，中间自带炮塔座圈凹槽 |
| 4573857 | 独立炮塔（主战）：带炮管、指挥塔、烟雾弹 |
| 4574431 | 无炮塔车体（重装）：座圈是**通孔**，需要补一块圆盘 |
| 4574443 | 独立炮塔（重装） |

生成参数：`version=G1, style=photorealistic, faceCount=60000, outputFormat=[glb], aiPredictSize=true`（沿用 `ArtSource/Lux3D/_prompts.txt` 的模板）。

**因为压根没切过，所以任何方向都不可能有洞。**

### 2.2 主战接上程序化履带

新模型自带履带（和车体焊在一起、不能动）。要恢复轻坦那套会转的履带，得先把模型自带的剥掉：

`work/strip_tracks.py`：删掉「z < 0.40×车高 且 |x| > 0.55×半宽」的面（主战删了 22151 / 58196 面）。剥完车体两侧敞开，但那个位置正好被程序化履带盖住。

然后 `proceduralTracks=true`，参数按剥掉那块区域实测：span 1.83 / band 0.56 / loop 8.20×1.10 / 轮 R0.40 ×6。

### 2.3 主战拆出独立炮管（恢复俯仰）

`work/split_barrel.py`：
1. 扫 360° 找炮管方向（判据：**远端顶点少 + 投影跨度大**。PCA 不行 —— 生成的炮塔接近正方形，主轴是宽度不是炮管）
2. 把炮塔转正，让炮管指向 −Y（Unity 里就是 +Z 正前方）
3. 沿炮管方向扫横截面，宽度突然变大处 = 炮盾，在那里 bisect 切一刀
4. 炮管原点搬到炮盾中心（= 俯仰转轴）

主战实测：炮管方向 230°（**生成时是斜着摆的**）、脖子在 30% 处、塔体 58332 面 / 炮管 1208 面、转轴 (0, 0.755, 2.101)。

### 2.4 工具：DevTankShots 截图台（凌晨那轮建的，这一轮一直在用）

`Assets/Scripts/Dev/DevTankShots.cs`，Play 模式下调用，用**游戏内第三人称机位**连拍 23 张 + dump 运行时数据。这一轮加了两项：
- `DevTankShots.TurretYawForShots`：截图前把炮塔转到指定角度（复现"转炮塔露洞"）
- dump 里的 `[height]` 段：车体离地、履带最低点、车体最低点

## 4. 下一步：先把主战炮塔对准（唯一该做的事）

### 现象
用户最后一张截图：炮塔明显偏右偏后，准星（屏幕中心）落在炮塔边缘而不是炮口方向。

### 已经量到的数据
用射线在甲板上打高度图（方法见 4.2），得到的座圈位置：

```
甲板高度图（相对车体原点 y；x 从左到右 −2.4..2.4，z 从上到下 −2.4..2.4）
z -0.6:  1.86  1.90 [1.49  1.47  1.45] 1.83  1.74   --
z  0.0:  1.90  1.95 [1.49  1.48  1.46  1.44] 1.77  --
z  0.6:  1.92  1.96 [1.50  1.49  1.47] 1.89  1.81   --
z  1.2:  1.92  1.94 [1.51  1.49  1.48] 1.87  1.83   --
```
方括号里是座圈凹坑（1.44~1.51），甲板面在 1.8~1.96。
**座圈中心大约在 x≈+0.1 / z≈+0.3，半径约 1.1 m。**

### 4.1 建议做法
1. 先用 4.2 的方法重新量一次（车体没动，数据应该一样，但要复算）
2. `modelTurretPivot` 设成量到的座圈中心 + 甲板高度
3. **注意 `DropToGround` 会整体下移模型**：def 里的 pivot 是"车体局部坐标"，运行时 `Turret.localPosition` 会比 def 里的 y 小约 0.54 m。改完要在 play 模式里读 `Turret.localPosition` 复核。
4. 复核标准：**正视时炮口应该在车体中线上，准星压住炮口**。用 `DevTankShots` 的 `01_behind` + 正面机位各拍一张。

### 4.2 量座圈高度图的方法（这段代码实测有效）
```csharp
var hull = go.transform.Find("Model");
var mf = hull.GetComponentInChildren<MeshFilter>();
var col = mf.gameObject.AddComponent<MeshCollider>();
col.sharedMesh = mf.sharedMesh;          // 车体网格必须 isReadable
for (float dz = -2.4f; dz <= 2.4f; dz += 0.6f) {
    for (float dx = -2.4f; dx <= 2.4f; dx += 0.6f) {
        var from = new Vector3(o.x+dx, o.y+8f, o.z+dz);
        var hits = Physics.RaycastAll(from, Vector3.down, 16f);
        float top = float.MinValue;
        foreach (var h in hits) if (h.collider == col && h.point.y > top) top = h.point.y;
        // top - o.y 就是该点甲板高度，最凹的一片就是座圈
    }
}
Destroy(col);
```

### 4.3 如果还是对不准
退路：**在 Blender 里直接把炮塔焊到车体上的正确位置**，导出成"整车 + 炮塔分离"两个 FBX，别再靠 def 里的 pivot 数字调。做法是在 `prep_v5.py` 里加一步：把 turret 按座圈中心平移后再导出，def 里的 pivot 固定写 (0, deckY, 0)。
