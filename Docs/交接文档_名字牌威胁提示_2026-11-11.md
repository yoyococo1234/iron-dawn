## 2. 实现要点（改之前先看这三条）

### 2.1 目标收集 + 视线判定必须放 `Update`，不能放 `OnGUI`

```csharp
void Update()
{
    PollCombatFx();
    if (Time.time < _radarNextScan) return;          // 0.15 s 节拍
    _radarNextScan = Time.time + 0.15f;
    _radarVehicles = Object.FindObjectsByType<VehicleCombat>(FindObjectsSortMode.None);
    PollNamePlates();                                 // ← 2026-11-11 新增，复用雷达节拍
}
```

`OnGUI` 一帧跑 3~4 遍（Layout / Repaint / 各种事件），在里面 `FindObjects` + `Linecast`
等于把成本乘 3~4。所以：

- `PollNamePlates()` 只负责**收集 + 判定**，结果塞进 `static List<NamePlate> _plates`；
- `DrawNamePlates()` 只做**投影 + 画**，纯读。

`NamePlate` 是 struct（`v` / `dist` / `los`），一次轮询最多十几个目标，GC 可忽略。

### 2.2 投影必须除以 `_scale`

```csharp
float px = sp.x / _scale;
float py = (Screen.height - sp.y) / _scale;   // Unity 屏幕坐标 y 向下，虚拟画布 y 也向下
```

和 2026-11-10 §5 第 5 条同一个坑：本工程所有 HUD 都在**缩放过的 `GUI.matrix`** 里画，
混用屏幕像素会整体偏右下（1440p 下偏 1/3 屏）。**任何新 HUD 元素都先过这一步**。

### 2.3 背后的点，屏幕坐标是镜像的

`Camera.WorldToScreenPoint` 对相机背后的点返回 `z < 0`，且 `x/y` 已经镜像过。
所以算方位箭头时要先取反：

```csharp
Vector2 d = new Vector2(sp.x - cx, -(sp.y - cy));
if (behind) d = -d;        // ← 少了这一行，身后的敌人会显示在正前方
```

箭头位置落在**内缩一圈的椭圆**上（不是矩形边框），下半部分的椭圆再缩 82 px，
避免压在底部模块状态 / 车辆信息面板上。

## 3. 本次踩的坑

| # | 现象 | 真因 | 处理 |
|---|---|---|---|
| 1 | 威胁箭头又小又暗，文字只剩一个 `m` | 箭头 `L=26`、文字框宽 120 贴着椭圆边缘，被裁掉；纯文字压在亮天空上几乎看不见 | `L=34`、线宽 4.4、文字 `_s20` + **暗底框**、椭圆内缩 132 px |
| 2 | 远处 986 m 的飞机一直在闪箭头 | 箭头没有独立距离上限，跟着名字牌的 1100 m 走 | 新增 `threatArrowRange = 700f` |
| 3 | 底部箭头压住模块状态条 | 椭圆是整圆，下边没让位 | `ry = VH*0.5 - (d.y < 0 ? 200f : 118f)` |
| 4 | **改完脚本进 Play 测试，`MatchManager.Instance` 变成 null** | **热重载后 Unity 不会重跑 `Awake`**，静态 `Instance` 被清空、对象还在场景里，于是 `Instance` 永远 null | 测试流程改成「**先退出 Play → RefreshAssets → 再进 Play**」；不要指望热重载后还能接着测 |

第 4 条不是这次新引入的 bug，是 Unity 的固有行为，但**每次改 HUD 脚本都会撞上**，记下来。

## 4. 怎么复验（照抄，别自己编）

```csharp
// 1) 进 Play，从封面进车库再部署
var gs = FindFirstObjectByType<GameStartScreen>(); gs.Begin(); await Delay(900);
GarageScreen.Instance.Close(); await Delay(400);
MatchManager.Instance.DeployPlayer(mainDef);   // mainDef = Vehicle_land_main
await Delay(2600);
var p = MatchManager.Instance.Player; p.hp = p.maxHp;   // 防测试期间被打死

// 2) 摆目标（关掉 AI，否则下一帧自己开走）
var e = 敌方陆战车; e.GetComponent<VehicleAI>().enabled = false;
e.transform.position = 贴地(p.transform.position + cam.forward * 130f);

// 3) 光标锁上，HUD 才画（DrawNamePlates 开头有 Cursor.lockState 判断）
Cursor.lockState = CursorLockMode.Locked;
await Delay(1100);   // PollNamePlates 是 0.15 s 节拍，等一拍以上
ScreenCapture.CaptureScreenshot(".../55_final.png");
await Delay(1100);   // 帧末写盘，必须再等
```

贴地用向下 `Raycast` 从 `y=800` 打下来，别直接用世界坐标（否则车悬空/埋地）。

## 5. 还没做的（原 §7.3 剩下的）

- **界面音量滑条**：`UiSound.Volume` 仍是硬编码 0.55，设置界面里没有滑条
- **结算面板「再来一局」按钮**：现在只有「按 R 重新开始」文字
- **车库/商店键盘操作**：只能点鼠标
- 名字牌**没有做"只看队友"或"只显示锁定目标"的开关**，也没有随难度缩放（`plateRangeGround/Air` 是
  `MatchHUD` 上的 public 字段，可以在 Inspector 里直接调，默认值按 2 km 地图 + 5v5 估的）
- 名字牌在**超宽屏**（`_vw` 远大于 1920）时水平间距会拉大，没专门适配（箭头有 `Mathf.Max(140f, ...)` 兜底）
