## 4. 流程要改（重要）

### 原来的顺序（有问题）

```
数据层 → 载具代码 → 地形 → 武器 → AI → 经济
```

**问题**：地形没定，载具的碰撞、穿模、卡墙根本没法验证；地形一改，载具参数全要重调。

### 新顺序

```
① 精细地形（形状 + 地表）
        ↓
② 载具适配地形（碰撞、贴地、坡度采样换成 Unity Terrain）
        ↓
③ 武器开火（炮塔/弹道/伤害）
        ↓
④ AI（跑在真地图上才有意义）
        ↓
⑤ 经济系统落地
        ↓
⑥ 细节物件 + 音效 + 特效
        ↓
⑦ 交付（构建/视频/报告书）
```

**核心原则：地形是一切的地基，先定地形再调载具。**

## 5. 精细地形用什么工具（不写代码）

| 方案 | 工具 | 要写代码吗 | 碰撞可靠吗 | 成本 | 结论 |
|---|---|---|---|---|---|
| **A. Unity Terrain + Terrain Tools** | Unity 官方免费包 | **不用** | ★★★★★ TerrainCollider 自动生成 | 0 | ✅ **推荐** |
| B. Blender A.N.T. Landscape | Blender 5.2 自带插件 | 不用 | ★★★ 要自己加 MeshCollider | 0 | 备选 |
| C. 外部高度图导入 | Unity Terrain 导入 RAW 高度图 | 不用 | ★★★★★ | 0 | 配合 A 用 |
| D. Lux3D 生成地形 | — | 要写代码接 | ✗ 物体级，不适合大地形 | 积分 | ✗ 不适用 |
| E. Asset Store 现成战场地形 | 免费/付费 | 不用 | ★★★★ | 0–几百 | 备选 |

### 为什么推荐 A

1. **完全不用写代码**——鼠标刷
2. **TerrainCollider 自动生成** → 物理和渲染用同一份数据，**从根上解决穿模/卡墙**
3. 支持**多层贴图**（沙/草/土/岩）按高度和坡度混合
4. 支持**导入高度图**：可以先用噪波生成基础起伏，再手动修
5. 自带树/草笔刷，细节物件可以直接撒

## 6. 具体操作步骤（Unity 里点哪里）

### Step 0 · 装 Terrain Tools 包
`Window → Package Manager → 左上角选 Unity Registry → 搜 "Terrain Tools" → Install`

### Step 1 · 建地形
`GameObject → 3D Object → Terrain`
- Inspector 里 Terrain 组件 → **Resolution** 设 513×513（够细）
- **Terrain Width / Length** = 120，**Height** = 20
- 位置归零

### Step 2 · 打底起伏
Terrain Tools 提供的 **Noise 笔刷**（或 `Paint Terrain → Raise or Lower Terrain` 配噪波）刷出大起伏。
参数建议：Scale 0.15、Strength 0.3，先把整体刷出丘陵感。

### Step 3 · 按区域塑形（对着 `Docs/战场设计.md` 的表）

| 区域 | 怎么刷 |
|---|---|
| 海域 z 20~60 | `Lower Terrain` 压到 **-6 m**（海平面在 -0.4） |
| 滩头 z 14~20 | `Smooth` 做成缓坡，从 -1 升到 0 |
| 中央城区 x -26~26 | `Flatten` 压平到 **0~2 m**（要能开坦克） |
| 山地 x<-26, z<-26 | `Raise` 抬到 **5~18 m**，用 `Smooth` 做出山脊 |
| 开阔地 x>26, z<-26 | `Flatten` 压到 **0~1 m** |
| 后方 x±26~60 | `Smooth` 做成 0~3 m 缓丘 |

### Step 4 · 地表材质
`Paint Terrain → Paint Texture` → `Add Layer` 加 4 层：
- **沙**（滩头、海边）
- **草**（平地）
- **土/岩**（山地）
- **雪**（山顶，可选）

材质来源：**ambientCG** 或 **Poly Haven**（都是 CC0，免费 PBR 贴图）。

### Step 5 · 细节物件
用 **Lux3D 生成**（20 积分/件）或 **Kenney CC0**：
- 岩石、树、废墟、路障、建筑
- 用 `Paint Trees` 或手动摆

### Step 6 · 水面
单独一个 Plane（y = -0.4）+ 半透明材质，覆盖海域区域。

### Step 7 · 载具适配（这一步要改代码，但很少）
把 `VehiclePhysics` 里的地形查询从自定义 `TerrainField` 换成 Unity `Terrain`：
- 贴地：`terrain.SampleHeight(worldPos) + terrain.transform.position.y`
- 坡度：`terrain.terrainData.GetSteepness(x, z)`
- 碰撞：TerrainCollider 自动，不用管

---

## 7. 关键提醒：碰撞从哪来

**这是你担心的"穿模/卡墙"的根因。**

现在载具用**自定义高度场**（`TerrainField.GetHeight`）算地面高度，和渲染用的是同一份数据，所以测试场没问题。

换成 Unity Terrain 后必须改成 `Terrain.SampleHeight`——**千万不要出现"渲染用 Terrain、物理用自定义网格"这种两套数据**，那才会穿模。

## 10. 这次踩过的坑（别再踩）

| 坑 | 现象 | 修法 |
|---|---|---|
| Unity API 升级弹窗 | 弹窗一出现，所有 MCP 调用排队超时，编辑器假死 | 点掉它；代码里别用废弃 API（`Rigidbody.velocity`→`linearVelocity`） |
| `AssetDatabase.Refresh()` 放在工具调用里 | 触发域重载，把正在执行的调用打断，连接卡死 | 改成只 `SaveAssets()`，或单独调用并接受超时 |
| `SaveScene` 目标目录不存在 | **静默失败**，场景根本没落盘（这次就是） | 先 `AssetDatabase.CreateFolder` |
| Unity 失焦 | Play 模式自动暂停，车只动 3 帧 | `Application.runInBackground = true` |
| MCP 会话失效 | 报 `Session not found` | `mcp_switch_off` 再 `mcp_switch_on` |
| 编辑器被强制关闭后 | 插件连不上 hub（工具数 0） | 重启 Unity；或重启 8080 服务器 |
| 水面 Plane 比地形大 | 整块地被水盖住 / 边缘露蓝 | 水面只盖水域，或低于地面 |
| 坡的 Lerp 方向写反 | 造出 5 米断崖 | `Lerp(高度, 0, t)` 而不是 `Lerp(0, 高度, t)` |
