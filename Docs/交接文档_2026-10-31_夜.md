## 0. 一句话现状

**三台坦克都换成了「车体 / 炮塔 / 履带分开生成再拼装」的模型：车体甲板完整、炮塔能真的转、履带能滚。**
黑洞问题的根子被绕开了 —— 不再是「整台车生成后切炮塔」，而是车体本来就没有炮塔。

---

## 1. 为什么放弃「整台车 + part_split 切炮塔」

`part_split` 会把炮塔连同**车顶一截甲板**一起切走，车体甲板上留一个破口；
车体是空心壳，从破口看到内壁 = 那块「黑洞」。

试过、都不行的路（别再走一遍）：

| 尝试 | 结果 |
|---|---|
| 深色圆盘盖住 | 洞比炮塔宽，盖不住；抬高一点又像一块板子叠在车上 |
| Blender `holes_fill` 补面 | 面片汤，洞不是干净边界环，补不准 |
| 运行时按炮塔底部截面算圆盘 | 位置偏前、半径偏小 |
| 顶点拍平 + 高度图实测补板（`WellFixup`） | 洞能盖住，但甲板被抹平、迷彩接不上，**越改越不像原车** |
| 重新生成整台车（同提示词同参数）再拆 | 拆出来是干净的圆形炮塔环，但**车长得不一样了** |

结论：**只要「切」，就一定缺一块**。要么换模型，要么不转炮塔。

## 2. 现在的做法（用户提的思路）

分别生成两份，再拼起来：

1. **HULL ONLY**：`... the HULL ONLY of a modern main battle tank, no turret, no gun: bare flat rectangular hull roof deck with a round recessed turret ring opening in the middle of the deck ...`
   → 车体自带一个圆形炮塔环，甲板完整
2. **TURRET ONLY**：`... a TURRET ONLY for a modern main battle tank, isolated part, no hull, no tracks, no wheels: wedge-shaped angular armored turret with a long 120mm gun, flat circular bottom base ...`
   → 炮塔自带圆形底座
3. 纯车体再 `part_split` 一次，把两条**履带**拆成独立零件（Unity 里滚 UV 让它转）

生成参数沿用 `ArtSource/Lux3D/_prompts.txt`：`version=G1, style=photorealistic, faceCount=60000, outputFormat=[glb]`，
只在提示词后面追加「炮塔独立 / 甲板平整」那两句。

### 拼装脚本 `work/assemble_tank.py`

```powershell
blender -b --python work\assemble_tank.py -- <name> <target_len> v4
# 例：blender -b --python work\assemble_tank.py -- main 8.6 v4
```

它会自动：

1. 车体按车长归一化（长轴转到 Y、水平居中、底面贴地）
2. 做俯视高度图找甲板高度；甲板缺失的连通块按「圆度 + 靠近车体中间」打分，挑出**炮塔环**（圆心 + 半径）
3. 车体零件里沿车长最长的那两块 = **履带**，单独拆出来
4. 炮塔：5° 扫一圈找「伸得最远、而且尖端附近点很少」的方向 = **炮口方向**，转到 +Y；
   量出底部圆的圆心/半径，缩放到炮塔环半径的 **0.97 倍**，平移到环心、底面落在甲板高度
5. 导出 `Assets/Models/Vehicles/Split/<name>_{hull,turret,tracks}_v4.fbx`
   + `ArtSource/Lux3D/<name>_assemble_report.json`（含转轴、环半径、缩放）

实测三台：

| 车 | 车长 | 炮塔环 圆心 / 半径 | 炮塔缩放 | 面数 hull/turret/tracks |
|---|---|---|---|---|
| light | 7.1 | (0.01, -0.11) / 0.96 | 0.777 | 31307 / 59795 / 28244 |
| main | 8.6 | (0.00, -0.25) / 1.10 | 0.922 | 36161 / 59535 / 21539 |
| heavy | 10.2 | (0.00, 0.16) / 1.17 | 0.676 | 24309 / 57117 / 32500 |

## 3. Unity 侧改动

| 文件 | 改动 |
|---|---|
| `VehicleDef.cs` | 新增 `useSplitTurret` / `modelTracksPrefab` / `modelTurretMaterial`；保留 `autoTurretWellPatch`（现在全关） |
| `VehicleModelBinder.cs` | 挂履带 + `TrackScroller`；炮塔用自己的材质；炮塔网格按 `modelTurretMeshOrigin - modelTurretPivot` 反偏移 |
| `TrackScroller.cs`（新） | **重算履带 UV**（u 沿车长按米铺）+ 程序生成的横向履带板贴图 + 按车速滚 u |
| `MapSceneBuilder.cs` | 不再覆盖已经配好的模型资产（只在 `modelPrefab` 为空时才自动找） |

**履带 FBX 必须 `isReadable = true`**（ModelImporter），否则运行时改不了 UV，滚动不生效 —— 这个已经设好并提交。

三台车的资产路径直接写在各自 `.asset` 里（`Assets/Models/Vehicles/Split/{light,main,heavy}_*_v4.fbx`），
贴图在 `Assets/Models/Vehicles/Textures/`，材质在 `Assets/Models/Vehicles/Materials/`。

## 6. 重做一台坦克的完整流程

```powershell
# 1. 生成两份（lux3d_text_to_3d，wait=false，G1 / faceCount 60000 / photorealistic）
#    <name>_hull_only.glb   <name>_turret.glb
# 2. 纯车体再拆件，把履带拆出来
#    lux3d_part_split(<name>_hull_only.glb) → <name>_hull_parts.glb
# 3. 拼装
blender -b --python work\assemble_tank.py -- <name> <车长> v4
# 4. 抽贴图
python work\extract_textures2.py ArtSource\Lux3D\<name>_hull_only.glb <name>_hull_v4
python work\extract_textures2.py ArtSource\Lux3D\<name>_turret.glb   <name>_turret_v4
# 5. Unity：建 2 个 Standard 材质（color 0.70），把三套 FBX + 两个材质填进 VehicleDef
# 6. tracks FBX 的 ModelImporter.isReadable = true
```
