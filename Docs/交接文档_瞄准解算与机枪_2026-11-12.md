## 1. 【已修】Esc 两层语义（11-11 §1 那条"还是没修好"）

### 真因

不是时序问题，是**两个组件抢同一个按键**：`GameStartScreen.Update` 读一次 `Input.GetKeyDown(Escape)`，
`MenuKeys.Draw` 又在 OnGUI 里读一次 `Event.current.KeyDown`。11-11 的补丁（`!MenuKeys.IsWaiting` 守卫）
只能保证"改键那一下不同时关面板"，但两个入口的顺序只要有一帧错位（OnGUI 的 KeyDown 被前面的
`e.Use()` 吃掉 / Update 先跑完守卫条件已失效），整块面板就退了。

### 修法：只留一个入口，按顺序判定

```csharp
// GameStartScreen.Update()
if (Input.GetKeyDown(KeyCode.Escape)) HandleEscape();

/// <summary>Esc 两层语义的唯一判定点（抽出来是为了能脱离键盘直接验）。</summary>
public void HandleEscape()
{
    if (_page == Page.Main) return;
    if (MenuKeys.IsWaiting) MenuKeys.CancelWaiting();   // 第一层：取消这次改键，面板留着
    else _page = Page.Main;                             // 第二层：返回主菜单
}

// MenuKeys：新增 CancelWaiting()；Draw() 里的 Esc 分支**整段删掉**
```

顺带加了 `public int PageIndex`（验收脚本用，不参与游戏逻辑）。

### 验证（`HandleEscape()` 可以直接调，不用注键盘）

| 步骤 | 结果 |
|---|---|
| 打开按键设置 → 点一行进入等键 | `page=1, IsWaiting=True` |
| Esc #1 | `page=1, IsWaiting=False` ✅ 只取消改键 |
| Esc #2 | `page=0` ✅ 回主菜单 |
| 游戏调整页 Esc | `page=0` ✅ |

> ⚠️ **仍然是"代码路径级"验证**：MCP 注不进真实按键事件，`Input.GetKeyDown` 那一下要人肉按一次确认。
> 但两层判定的逻辑本身已经用上面四步跑过了，不再是"推演"。

## 4. 【已修·重点】舰艇「Ctrl 锁定 + 开镜」瞄不准

### 4.1 11-11 文档猜的方向是错的

文档猜的是"炮管俯仰用鼠标 pitch 线性反解，开镜后 FOV 变了就分叉"。
**实测四组数据后排除**：开镜时 `CameraFollow` 的 `_scoped` 分支是"相机**沿着炮管真实朝向**看"，
根本不经过 `camFollow.pitch` 反解，所以那条路径不成立。

### 4.2 真因（两个坐标系错误，叠加）

先看实测（炮艇，目标 400 m，开镜 + 锁定）：

```
炮管 → 目标   1.55°      ← 打出去就偏 ~10 m
镜心 → 目标   1.24°
船体 euler    x=358.79  z=358.07   ← 随浪俯仰 -1.2°、横滚 -1.9°
```

**① 基准点用了"船体中心 + 2.5 m"，而炮艇的炮口在船头 —— 差 8 m。**
`GetMuzzlePosition()` 实测离船体中心 8.0 m。用中心算方向，400 m 处固定偏 `atan(8/400) = 1.1°`。

**② 炮塔角是"相对船体"的，旧写法只减了船体偏航，没算船体俯仰/横滚。**
`AimDirect(世界偏航, 俯仰)` 内部 `want = DeltaAngle(船体yaw, 世界yaw)`，
于是"船体姿态 ∘ 炮塔角"里多了一层船体姿态 —— 船在浪里横滚 2°，炮管就固定歪 2°。

两处叠加 = 实测 1.55°。

**为什么"不开镜时看着是好的"**：第三人称的准星（`MatchHUD.DrawCrosshair`）用的是
`Euler(-barrelPitch, 船体yaw + turretYaw, 0)` 这个**理想解算**，不是真实炮管 —— 它画在目标上，
而真实炮管歪着；50° 视野下 1.5° 只有 3% 屏宽，看不出来。开镜时镜心 = **真实炮管**（相机沿炮管看），
14° 视野下 1.5° 就是 100 多像素 —— 一开镜立刻暴露。

### 4.3 修法

1. **基准点换成真实炮口**：`_combat.Physics.GetMuzzlePosition()`。
2. **方向转进船体坐标系再拆角**（新增 `VehiclePhysics.AimDirectLocal(relYaw, pitch, 转速)`）：

```csharp
Vector3 localDir = _combat.transform.InverseTransformDirection(lockDirWorld);
float relYaw  = Mathf.Atan2(localDir.x, localDir.z) * Mathf.Rad2Deg;
float localPitch = Mathf.Asin(Mathf.Clamp(localDir.y, -1f, 1f)) * Mathf.Rad2Deg;
_combat.Physics.AimDirectLocal(relYaw, localPitch, turn);
```

3. **低通只滤"世界俯仰"**，不滤本地角 —— 本地角本来就该跟着船体姿态抖，一滤就跟不上，炮管又歪回去。
4. **炮镜视差**：机位在炮塔上方、不在炮管轴线上（差 2~4 m），"沿炮管平推 300 m"是平行线，
   350 m 处镜心比弹着点高 0.5°。改成**先沿炮管找命中点，再从实际机位看那个点**（`CameraFollow` `_scoped` 分支）。
5. **第三人称准星跟着改**（`MatchHUD`）：`dirStable = 船体rotation * Euler(0,turretYaw,0) * Euler(-barrelPitch,0,0) * forward`，
   和真实炮管同一套。锁定后炮管主动抵消船体姿态，准星反而是**稳的**。

### 4.4 修完的实测（同一场景、同一目标距离）

| 距离 | 炮管→目标（修前） | 炮管→目标（修后） | 镜心→目标（修后） |
|---|---|---|---|
| 150 m | — | 0.13° | 0.06° |
| 400 m | **1.55°** | **0.13°** | 0.12° |
| 800 m | — | 0.38° | 0.45° |
| 1100 m | — | 0.45° | 0.49° |

> 800 m 以后的 0.4~0.5° **不是误差**：那是弹道下坠补偿（800 m/s 弹速、1100 m 飞行 1.4 s，掉 9.3 m ≈ 0.48°）。
> 炮管本来就该比视线高这么一点，炮弹才会落到目标上。

## 5. 【已修】舰艇机枪「索敌」—— 三个独立问题

### 5.1 枪架卡在 ±120°（这是"索敌瞄不到人"的主因）

枪架是独立回转座 `MG_Yaw`，挂在**炮塔**下面，`mgYawLimit = 120`；而机枪模式下炮塔**完全不转**。
于是"枪架覆盖范围 = 炮塔当前朝向 ±120°"。实测（把视角绕船转一圈，看枪管和镜头差多少）：

| 视角偏离船头 | 修前 枪管 vs 镜头 | 修后 |
|---|---|---|
| 0° / 80° / 150° | 1.1~1.5° | **0.00°** |
| **160°** | **40.0°**（枪架卡死） | 0.00° |
| **180°** | **60.0°**（枪架卡死） | 0.00° |

**修法**：机枪模式下让**炮塔慢速跟着视角转**（新增 `VehiclePhysics.RotateTurretToward(worldYaw, 转速)`，
用炮塔自身转速 50°/s），枪架只做剩下的快速微调（200°/s）。
炮艇 `turretYawLimit = 150` + `mgYawLimit = 120` → 合计覆盖 270°，**全向无死角**。
体感上仍然是枪架在快速跟手，炮塔只是慢慢挪过去把底座摆正。

### 5.2 同一套坐标系错误（和 §4 同源）

修前"枪管 vs 镜头"恒差 1.1~1.5°（船体横滚/俯仰没算进去）。新增
`VehiclePhysics.AimDeckGunWorld(worldDir, ...)`：世界方向先转进**机枪回转座的父坐标系**（炮塔，含船体姿态）再拆角。修后 0.00°。

### 5.3 机枪开镜时画面正中全是枪自己的模型

`MG_SightRing0~15`（环形准星）、`MG_TopCover`、`MG_Jacket` 就在机位前 **1.2~1.5 m**，
开镜后正中一块黑铁 —— 目标被挡在后面。这就是"瞄不到人"的另一半。

**修法**：机枪开镜时把**枪身自己的渲染体藏掉**（`CameraFollow.SyncMgVisibility()`，
隐藏 `mgYawBone` 下 33 个 Renderer），退出开镜/玩家死亡/组件关闭时自动还原。
HUD 本来就有机枪分划（细圆环 + 密位 + 中心红点 + 倍率），模型留着只会挡视线。

验收图：`Docs/UI_机枪开镜_修复前_枪身遮挡_20261112.png` → `Docs/UI_机枪开镜_枪身已隐藏_20261112.png`
→ `Docs/UI_机枪开镜_300m锁定目标_20261112.png`（300 m 目标连名字牌一起清清楚楚）

### 5.4 锁定距离被压到 600 m

`LockOnSystem.PickTargetInCone` 里 `lockRange = mgMode ? min(武器射程, 600f) : 武器射程`。
而机枪 `mg_aa` 射程 **850 m**、弹速 900 m/s —— 700~850 m 之间明明打得到却**锁不上**。
**修法**：去掉 600 上限，直接按武器射程。实测 800 m 目标：`锁定=True / 射程内=True / 枪管vs目标=0.44°`。
