## 1. 瞄准解算：开镜 + Ctrl 锁定瞄不准（1.55° → 0.13°）

**真因（两个坐标系错误叠加，不是 11-11 文档猜的"鼠标 pitch 反解"）**

1. 解算基准点用"船体中心 + 2.5 m"，而炮艇炮口在船头 —— **差 8 m**，400 m 处固定偏 1.1°；
2. 炮塔角是**相对船体**的，旧写法只减了船体偏航，没算船随浪的**俯仰 −1.2° / 横滚 −1.9°**。

**修法**：基准点换 `GetMuzzlePosition()`；世界方向 `InverseTransformDirection` 转进船体坐标系再拆角
（新增 `VehiclePhysics.AimDirectLocal` / `AimDeckGunWorld`）；低通只滤世界俯仰；炮镜改成
"沿炮管找命中点、从实际机位看那个点"消除机位视差；第三人称准星乘上船体 rotation 与真实炮管对齐。

**实测**：400 m 炮管→目标 1.55° → **0.13°**；1100 m 0.45°（那是弹道下坠补偿，属正确值）。

## 2. 机枪"索敌瞄不到人"：三个独立问题

1. **枪架卡死**：枪架挂在炮塔下、只有 ±120°，而机枪模式炮塔不转 → 视角偏 160° 时枪管和镜头差 **40°**、180° 差 **60°**。
   改成炮塔 50°/s 跟随视角 + 枪架快速微调 → 各角度 **0.00°**，全向无死角。
2. **同一套坐标系错误**（枪管恒差 1.1~1.5°）→ 修后 0.00°。
3. **开镜后画面正中全是枪自己的模型**（`MG_SightRing0~15`、`MG_TopCover` 在机位前 1.2~1.5 m）→
   开镜时隐藏枪身 33 个渲染体，退出/死亡自动还原。
4. 机枪按 Ctrl 锁不上远处：**现在统一压到 500 m 以内才锁**（见 §3）。

## 3. 锁定规则调整（用户 11-12 要求）

- **锁定距离上限 500 m**（机枪、舰炮、主炮一律），超过只能自己瞄：`LockOnSystem.LockRangeCap = 500f`；
- **鱼雷/慢速武器不做提前量**：弹速几十 m/s 按弹速算会得到上百米提前量，准星飞得老远（用户原话"鱼雷 Ctrl 瞄准都歪了"）。
  现在 `projectileSpeed < 300` 或 `isTorpedo` 直接指向目标；
- **机枪模式按机枪自己的弹速算弹道/提前量**（以前拿炮塔那把武器，炮艇可能是鱼雷 → 全错）。

## 6. 命数 / 复活 / 车库 / 按键

| 问题 | 修法 |
|---|---|
| 三条命用两条就复活不了 | ①**首次出击不扣命**（3 条命 = 开局 1 次 + 复活 3 次）；②复活时钱不够最便宜载具 → 自动补「复活补给 +N 金」；③**车库开着时不判负**（`CheckTeamWipe` 加守卫） |
| G 回车库后没法取消 | 车库 `Update` 里加 **Esc**：有车时 Esc = 取消换车（不扣命不扣钱）；无车时不响应 |
| R 键没用 | **删掉 R**（按键设置里也删了）；改成**暂停面板底部「重新开始本局」按钮**，点两次确认；顺手修了从暂停重开时 `timeScale/Paused` 没复位的坑 |
| 暂停后想退出 | **暂停时按 Esc 直接退出暂停**；暂停面板新增**「换载具」按钮** |

## 9. Unity-MCP 连不上（今天最耗时的一件）

**真因**：插件 1.11.0 的 `McpServerManager.ServerVersion` **写死 9.5.0**，本机两份 server 是 9.4.3 / 9.4.4 →
插件去 GitHub 下 9.5.0，而 **release 资产下载被墙**（api.github.com 能通，releases/download 不通）→ 不启动也不连接。

**修法**：用插件自带的离线兜底 `UNITY_MCP_SERVER_PATH`
→ `E:\Tools\mcp-servers\unity-mcp-server-9.4.4\gamedev-mcp-server.exe`（9.4.4，含 version 文件）。
实测 **插件 1.11.0 ↔ server 9.4.4（API 2.0.0）完全兼容**，握手成功、工具调用正常。

⚠️ **坑**：`setx` 只对**之后新启动**的进程生效；DSH 的 pwsh 里 `$env:UNITY_MCP_SERVER_PATH` 仍是空，
**启动 Unity 时必须显式带上**（命令见 memory `2026-11-12-UnityMCP连不上修复.md`）。

**顺带定下两条规矩**：① 长活（打包）走 `BuildCli.BuildWindows` batchmode，**不塞进 MCP**；
② 改完脚本 `RefreshAssets()` 会触发域重载、插件必然重连，**先轮询 8080 变 ESTABLISHED 再调 MCP**。
